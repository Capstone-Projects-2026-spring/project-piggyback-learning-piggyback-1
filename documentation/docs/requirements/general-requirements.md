# General Requirements

## For Parents and Admins

- Desktop or laptop running Windows, macOS, or Linux
- Modern web browser (Chrome, Firefox, or Edge recommended)
- Internet access
- A microphone (required for children to answer quiz questions by voice)

## For Running the App Locally

- Python 3.12 (exactly - other versions are not supported)
- FFmpeg installed and on your system PATH
- Node.js LTS (optional, improves YouTube download reliability)
- API keys for at least one AI provider (OpenAI, Anthropic, or Gemini) to generate questions for new videos

## For Kids

- A parent-provided access code to log in
- A microphone to answer questions out loud
- Any device with a browser and internet connection
